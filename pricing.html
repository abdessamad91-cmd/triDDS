Questions fréquentes

Comment se passe le mois d'essai ?

Vous recevez un accès complet pour une déchèterie, avec vos agents déjà créés. Au bout d'un mois, soit vous continuez et la première facture part, soit l'accès se ferme. Rien n'est prélevé automatiquement.

Qu'est-ce qu'un scan photo ?

Une photo analysée par l'IA pour lire les étiquettes et classer les produits. Une photo compte pour un scan, même si plusieurs produits y figurent. La recherche par nom n'est jamais décomptée.

Que se passe-t-il si le quota est atteint ?

La recherche continue de fonctionner normalement. Les scans reprennent le 1er du mois suivant, ou plus tôt si vous passez à l'offre supérieure.

Faut-il installer une application ?

Non. TriDDS s'ouvre dans le navigateur du téléphone et peut être ajouté à l'écran d'accueil. La recherche fonctionne même sans réseau.

Qui peut se connecter ?

Uniquement les profils créés pour votre site, avec le code du site. Un profil ne peut être connecté que sur un appareil à la fois. En cas de besoin, le code peut être changé.

Le classement est-il fiable ?

La base suit le référentiel EcoDDS. Les lectures IA incertaines sont signalées « à vérifier » et l'agent garde toujours la décision finale.

Peut-on ajouter nos propres produits ?

Oui, à partir de l'offre Pro : le responsable du site ajoute des fiches qui apparaissent dans la recherche de toute l'équipe.
